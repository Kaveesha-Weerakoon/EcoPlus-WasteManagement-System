# ♻️ Eco Plus - Non-Biodegradable Waste Management System

Welcome to **Eco Plus**, a fully functional waste management system designed to optimize the handling of **non-biodegradable waste**. This project demonstrates how a robust and feature-rich web application can be built **entirely from scratch without any frameworks**.

---

## 🌟 Key Functionalities

- ⭐ **Online Garbage Collection Requests**  
  Users can request garbage collection services conveniently from home.

- ⭐ **Regional Center Management**  
  Efficient handling and coordination of regional waste collection centers.

- ⭐ **Eco Credits System**  
  Users earn eco-credits for responsible waste disposal.

- ⭐ **Supermarket Discount Integration**  
  Redeem eco-credits for discounts at partnered supermarkets.

- ⭐ **User Registration and Access Control**  
  Secure and seamless user account management.

- ⭐ **Feedback Mechanism**  
  Users can submit feedback to help improve the service.

- ⭐ **Discount Management**  
  Admins can manage and update supermarket discount offers.

- ⭐ **Waste Collection Analytics**  
  Visualize waste collection data and generate insights.

- ⭐ **Garbage Stock Release Management**  
  Manage the release of collected waste stocks to recyclers or other stakeholders.

- ⭐ **Notifications System**  
  Keep users updated with real-time collection alerts and updates.
